# wifehuck

Wi-Fi Cracker v3.0 — это программа для аудита безопасности беспроводных сетей стандарта IEEE 802.11 (2.4 ГГц, каналы 1–13). Возможности:
Сканирование точек доступа — видит BSSID (MAC-адрес роутера), ESSID (имя сети), канал, уровень сигнала (RSSI в dBm), тип шифрования (WPA/WPA2/WEP). Точность частоты: 2412 МГц для канала 1 ±0.0001 ГГц.
Захват WPA 4-way handshake — отправляет deauth-пакеты (тип 0, подтип 12, 5 штук) для принудительной переподключения клиента, после чего перехватывает EAPOL-кадры. Таймаут захвата: 90 секунд ±0.5. Сохраняет результат в .pcap.
Перебор пароля по словарю — через aircrack-ng с файлом rockyou.txt (можно заменить любой другой UTF-8 без BOM). PBKDF2-HMAC-SHA1, 4096 итераций, выход 256 бит.
Интерфейс в терминале — управление стрелками (выбор сети), Enter (взлом), Q (выход).
Не может (без доработки): взлом WPA3, работа на 5 ГГц, перебор по маске, атака через PMKID (требуется изменение кода).

Как пользоваться:
Требования:
Адаптер Wi-Fi с поддержкой мониторного режима и инъекции кадров (чипы: Atheros AR9271, MediaTek MT7612U, Ralink RT3070).
ОС: Debian/Ubuntu/Kali Linux (ядро ≥6.1.0).
Права root.

Установка (одна строка в терминале):
bash
sudo apt update && sudo apt install -y aircrack-ng tshark python3 curses
Запуск:
Сохранить скрипт как cracker.py

Дать права: chmod +x cracker.py

Запустить: sudo python3 cracker.py

Пошагово в интерфейсе:
Скрипт сам переводит wlan0 в мониторный режим.
Ждёте 15 секунд — сканирование сетей.
Стрелками вверх/вниз выбираете цель.
Нажимаете Enter — автоматический захват handshake (до 90 сек) и перебор пароля.
Если пароль найден — отобразится на экране зелёным цветом.

Для выхода: нажмите Q.

Проблемы и решение:
Ошибка «wlan0mon не найден» — замените в коде wlan0mon на wlan0 (если интерфейс не переименовывается).
Нет handshake — подойдите ближе к роутеру (мощность передачи 20 дБм ±1.5 дБ хватает на 30–50 м в помещении).
Словарь не работает — укажите свой путь в переменной WORDLIST_PATH (абсолютный путь к файлу).
